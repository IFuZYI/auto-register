# 不重写：分层剥离，数据层先行

本仓 52,454 行生产代码里没有参考实现（`reference/` 不存在，注释引用的
`/home/chatgpt2api/internal/service/password_login.go` 也不在本机），157 个 commit
里只删过 2 个测试文件 —— **被删掉的模块（payment / team_manager / codex_proxy /

**决定：不重写，按 `core → 能力 → 编排` 分层剥离；第一阶段零平台改动。**

## 考虑过的替代方案

- **推倒重写**：被否。293 条注释是唯一行为规格，重写等于把「Cloudflare 按家族封」
  「add-phone 墙」「OTP 串号」这些用真实账号换来的结论清零，然后重新踩一遍。
- **先做功能冻结再大重构**：被否。7–10 周无交付，而当前线上问题（RT 为空、
  client_id 缺失）还在发生。
- **只重构 ChatGPT 链路**：被否。数据层与能力层是跨平台的，只改 chatgpt 会在
  Grok 上留下第二套模式，等于把「双模型」问题复制成「双能力层」。
- **先补文档再决定**：采纳为阶段 0 的前置动作，但不作为替代方案 —— 文档化本身
  不改变代码结构。

## 后果
