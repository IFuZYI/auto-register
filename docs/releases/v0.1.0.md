v0.1.0 — 首个公开版本

多平台账号自动注册与管理系统：插件化平台层 + Web 管理台 + 邮箱号池 + 面板同步。

## 亮点

- **平台**：ChatGPT（纯协议，无需浏览器）· Grok（camoufox 浏览器路径）
- **邮箱**：iCloud 隐私邮箱（本地生成 / 远程仓库）· Outlook / Hotmail 号池
- **面板**：CPA（CLIProxyAPI）· Sub2API · grok2api · chatgpt2api，双向对比后推送/拉回
- **凭据**：AES-256-GCM 全量加密（password / AT / RT / IDT / ST / SSO / 2FA / cookies），
  列表接口只回布尔，详情接口带 no-store
- **部署**：单镜像（后端 + 前端 + Solver）、单卷 /runtime、HEALTHCHECK、内存与 PID 上限
- **维护**：自动刷新 / 探测 / 补 RT / 绑 2FA / 清理日志，间隔可配（m/h/d）

## 部署注意

1. **必须单进程** —— iCloud 取号互斥是进程内锁，加 replicas 会领到同一个邮箱
   （详见 docs/MAINTENANCE.md §1.6）
2. **先设面板密码** —— 未设密码时拒绝一切非本机请求
3. **备份要带密钥** —— `data/secrets/credential_key` 丢失 = 凭据不可恢复
4. Solver `:8889` **无鉴权** —— 默认只绑回环，对外请自行加反代与鉴权
