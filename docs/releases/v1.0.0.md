v1.0.0 — 多平台账号管理（AWS / Kiro 落地）

首个 1.0 版本：在 v0.1.0 的 ChatGPT / Grok 双平台之上，补齐 **AWS / Kiro** 平台、
导入导出契约、自动维护周期任务与整站前端重构。自 v0.1.0 起 34 个提交。

## 亮点

- **平台**：ChatGPT（纯协议）· Grok（camoufox 浏览器）· **AWS / Kiro**（新增）
  - AWS 来源三选一：复用已有账号 / 指定账号 / 新建账号
  - 「授权账号」二级菜单 + 台账化视图（行内授权链、脚注、抽屉去重）
  - 半成品 AWS 号落库 + 一键补 Kiro（指纹金标测试守住）
- **导入导出**：Kiro「导出凭据」改为 **Agent2API 导入格式**（id/email 唯一、loginProvider 小写）；
  AWS SSO 走 **AWS OIDC** 刷新；CSV 补三列、来源快照、camelCase 归一，旧行有兜底别名
- **自动维护**：AWS / Kiro 接入周期任务 —— 20 个配置键、4 条任务、面板分区；
  探测成功写回、indeterminate 语义、注册遍历按平台
- **前端**：全量设计优化 —— 仪表盘库存带、代理页 / 注册页布局、质量地板；
  「授权账号」改为二级菜单，AWS 作为子项
- **凭据**：AES-256-GCM 全量加密（password / AT / RT / IDT / ST / SSO / 2FA / cookies），
  列表接口只回布尔，详情接口带 `no-store`

## 已知问题（本版未修，逐条带 file:line）

检测共登记 **41 条 P1**，按影响排序的前 19 条列在
`docs/audit/2026-11-15-full/SUMMARY.md` 第四节，全部带复现证据。最需要留意的四条：

1. **`core/storage/account_store_json.py`** —— JSON 后端 `update` 是 get+put 两个临界区：40 线程并发只剩 8 个字段更新（实测）。

3. **`core/db/migrations.py:881` / `core/db/__init__.py:122`** —— 手写迁移链不补 `accounts.legacy_id`；应用自建库无 `alembic_version`，`alembic upgrade head` 必失败。
4. **`services/external_sync.py:251`** —— 贡献模式会把 CPA 管理口令当 Bearer 发给第三方，默认地址是明文 HTTP（需显式开启 `contribution_enabled`）。

**安全提示**：`tools/resin_pair_probe.py` 里的代理口令曾随历史提交公开，改代码不会让它失效 ——
请在代理商后台**轮换该出口密码**；需要清理 git 历史请自行执行 `git filter-repo` 后强推（本版未做）。

## 升级注意

1. **必须单进程** —— iCloud 取号互斥是进程内锁，加 replicas 会领到同一个邮箱
   （见 `docs/MAINTENANCE.md` §1.6）
2. **先设面板密码** —— 未设密码时拒绝一切非本机请求
3. **备份要带密钥** —— `data/secrets/credential_key` 丢失 = 凭据不可恢复
4. Solver `:8889` **无鉴权** —— 默认只绑回环，对外请自行加反代与鉴权
5. 从 v0.1.0 升级：直接替换镜像即可，启动时自动跑迁移（`run_migrations()` 幂等）；
   建议先 `GET /api/backup/export` 留一份带密钥的备份
