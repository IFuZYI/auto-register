# T0.4 数据快照（生产侧执行）

**本 worktree 没有 `data/` 目录**，所以快照与基线导出必须在部署机执行。
阶段 0 的门禁里这一项标注为「待生产侧确认」，不阻塞其它任务。

## 1. 目录快照

```bash
cd <生产仓库根>
tar czf ~/data-snapshot-$(date +%F-%H%M).tgz data/
tar tzf ~/data-snapshot-*.tgz | wc -l        # 记录文件数
du -sh data/                                  # 记录体积
```

**验证可还原**（在临时目录里解一次，别动线上）：

```bash
mkdir -p /tmp/restore-check && tar xzf ~/data-snapshot-*.tgz -C /tmp/restore-check
sqlite3 /tmp/restore-check/data/account_manager.db "select count(*) from accounts;"
```

## 2. 账号基线导出（dump diff 的 before）

```bash
cd <生产仓库根>
python scripts/dump_accounts.py --platform chatgpt > ~/accounts-before-chatgpt.json
python scripts/dump_accounts.py                     > ~/accounts-before-all.json
```

凭据字段已打码成 `sha256:<12>:len<N>` —— 值变了指纹会变，原文不会落到文件里。
所以这份基线**可以**归档进备份，不必当密文处理。

## 4. 阶段 1 结束时的 after 对比

```bash
python scripts/dump_accounts.py --platform chatgpt > ~/accounts-after-chatgpt.json
diff <(jq -S 'map(del(.updated_at))' ~/accounts-before-chatgpt.json) \
     <(jq -S 'map(del(.updated_at))' ~/accounts-after-chatgpt.json)
```

空 diff = 数据层行为等价。非空则逐条解释并记进 `docs/refactor/DIFF-LOG.md`。
