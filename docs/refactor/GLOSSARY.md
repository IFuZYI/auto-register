# 重构语言

描述这套代码**结构**的词汇，与产品领域（账号、邮箱、面板）无关。
存在的理由：同一个词在讨论里被当成三件事用（「动作」「能力」「路径」混着说），
导致「合并重复」与「删功能」被混为一谈。

## 语言

**能力（Capability）**：
平台对外提供的一类操作，按语义划分：探测、刷新、上传、同步状态、补凭证、绑 2FA、配额。
一个能力可以有多个历史实现，但只应有一条现役路径。
_Avoid_: 动作、操作、action

**动作 id（action id）**：
`execute_action` 的字符串入参，现役 17 个。是历史产物，重构后降级为兼容适配层，不再作为变更单元。
_Avoid_: 能力（两者不是同义词）

**路径（path）**：
达成同一语义的一条实现路线。拿 RT 有「Codex」与「登录」两条路径；代理绑定现有三条路径。
_Avoid_: 分支（分支是控制流，路径是实现）

**观测（observation）**：
一次探测或刷新得到的原始结论（http_status、error_code、state），原样存进 `extra`，不做解释。
例：`chatgpt_local`、`chatgpt_token_refresh`。
_Avoid_: 状态、结论

**意图（intent）**：
用户选择的配置（`chatgpt_registration_mode`、`bind_2fa`）。与观测正交：意图说想怎样，观测说实际怎样。
_Avoid_: 配置（太泛）、模式

**派生（derived）**：
由观测与意图算出来的值（`status`、`has_refresh_token`）。原则是**不落库**；必须物化时只允许一处写入。
_Avoid_: 冗余字段、缓存

**事故保险（incident insurance）**：
由一次真实故障催生、并在注释里留下实测数据的分支。删它等于赌故障不复现。
_Avoid_: 冗余代码、防御性编程（后者是通用概念，不特指本仓）

**最小集（minimal set）**：
每个能力只有一条路径、每个语义只有一个定义处的状态。**不是行数最少**。
_Avoid_: 精简、瘦身

**减法 A / B / C**：
A = 合并等价路径（安全，有测试兜底）；B = 删除产品能力（需产品决策）；C = 删事故保险（禁止）。
_Avoid_: 清理、优化

**字段级 diff（dump diff）**：
重构前后对同一批账号导出 JSON 逐字段比较。空 diff = 数据层行为等价，比「测试全绿」更强的证据。
_Avoid_: 回归测试（那是另一回事）
