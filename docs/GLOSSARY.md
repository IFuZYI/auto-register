# 账号管理台

多平台账号自动注册与管理系统。本术语表只收**本项目特有**的概念（通用编程
概念不在此列）；「邮箱服务」这一域讲的是「注册用的邮箱从哪来、怎么消耗」。

## Language

**主号（iCloud）**：
Apple ID 账号，是隐私邮箱别名的来源。凭据（Cookie / App 专用密码）在本机库
或远程仓库里。
_Avoid_: 母号、母邮箱

**隐私邮箱（HME）**：
由 iCloud Hide My Email 生成的别名地址，注册时发给目标站点收验证码。
_Avoid_: 别名邮箱、临时邮箱

**本地 / 远程（来源，`source`）**：
一条主号或别名记录从哪来。`local` = 本机直连 Apple 维护；`remote` = 从独立
icloud-hme 服务同步的镜像。
_Avoid_: 线上/线下、真号/假号

**远程仓库**：
独立部署的 icloud-hme 服务。主号凭据与 SRP 登录都留在它那边，本机只存
「服务地址 + 管理员密码（密文）+ 远端账号 id」。
_Avoid_: 远程面板、远端服务端

**远端账号**：
远程仓库里的一个账号（它那边的 `acc_xxx`）。接入本机后成为一行
`source=remote` 的主号记录。
_Avoid_: 远程主号（会与本地主号混淆，除非在讲对比语境）

**本地优先（去重）**：
同一个邮箱地址在本地与远程都存在时的合并规则：保留本地行，远程行不建立、
不覆盖。见 [ADR-0001](adr/0001-icloud-remote-repo.md)。

**号池（邮箱池）**：
可被注册任务领取的邮箱地址集合。状态：`unpooled`（未入池）/ `available`
（可领）/ `in_use`（使用中）/ `used`（已用）。
_Avoid_: 邮箱库、地址池

**按平台消耗**：
邮箱的「已用」只对用掉它的那个平台生效（`,chatgpt,grok,` 记账）——同一个
地址注册过 ChatGPT 仍可注册 Grok。
_Avoid_: 一次性邮箱（不准确：它只对单个平台一次性）

**渠道（邮箱渠道 / provider）**：
可插拔的收件来源实现（`microsoft` / `icloud_local` / `icloud_remote`）。
注册页按 provider 选渠道、按渠道配置取号范围。
_Avoid_: 邮箱服务（那是界面一级菜单的名字，渠道是它的实现）

**面板**：
注册产物的下游消费方（CPA / Sub2API / grok2api / chatgpt2api），全部是独立
部署的远程服务。与「远程仓库」是两回事：面板消费账号，远程仓库提供邮箱。
_Avoid_: 远端（远程仓库才是「远端」）
